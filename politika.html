2. КАКИЕ ДАННЫЕ ОБРАБАТЫВАЮТСЯ И ЗАЧЕМ

2.1. Покупатели в Telegram-боте: идентификатор Telegram-аккаунта, номер счёта, сумма, статус заказа, даты оплаты и выдачи файла. Имя пользователя или имя из профиля Telegram приходит Оператору в уведомлении об оплате, в базе бота оно не сохраняется. Цели: выдать оплаченный файл, отправить его повторно по запросу покупателя, ответить на обращения по заказу, вести налоговый учёт.

2.2. Покупатели на странице оформления заказа https://pay.ai-toolbox.ru: адрес электронной почты, номер заказа, сумма, статус заказа, даты оплаты и отправки файла. Цели: отправить оплаченный файл письмом, отправить его повторно по запросу покупателя, ответить на обращения по заказу, вести налоговый учёт. Согласие на обработку этих данных покупатель даёт отдельно, отметкой в форме заказа; текст согласия: https://pay.ai-toolbox.ru/soglasie. Вместе с заказом сохраняется редакция согласия, которую отметил покупатель.

2.3. Обращения на почту и по телефону: адрес почты или номер телефона, имя, если его указали, и текст обращения. Цель: ответить на обращение.

2.4. Посетители сайта. На сайте https://ai-toolbox.ru нет форм и файлов cookie. Чтобы считать посещаемость, страница сообщает серверу https://pay.ai-toolbox.ru о просмотре: метку источника из ссылки, если она есть, и адрес сайта, с которого пришёл посетитель. Сервер хранит только число просмотров за день по каждому источнику, без IP-адресов и других сведений о посетителе. Сайт размещён на хостинге GitHub Pages. По документации GitHub, при посещении сайта на GitHub Pages IP-адрес посетителя записывается и хранится в целях безопасности. Эти записи ведёт GitHub, Оператор их не получает.

2.5. Посетители страницы оформления заказа. На странице https://pay.ai-toolbox.ru нет файлов cookie, сервер не записывает посещения в журнал. Он хранит только число просмотров страницы и заказов за день по источникам, без сведений о посетителях. IP-адрес посетителя используется только в оперативной памяти сервера, чтобы ограничить число заказов и учтённых просмотров с одного адреса, и в базу данных не записывается.

2.6. Данные банковской карты покупатель вводит на странице Робокассы, при покупке в боте там же указывает имя и адрес электронной почты. Их обрабатывает Робокасса по своим правилам. Оператору они не передаются, кроме сведений, необходимых для чека.

Данные покупателей на странице оформления заказа обрабатываются также на основании их согласия (п. 1 ч. 1 ст. 6 Закона № 152-ФЗ).

4. КАК ОБРАБАТЫВАЮТСЯ ДАННЫЕ

4.1. Обработка автоматизированная: сбор, запись, хранение, использование и удаление. Данные о заказах хранятся в базах данных бота и страницы оформления заказа на сервере в Москве (Российская Федерация), письма в почтовом ящике Оператора на Яндекс Почте.

4.2. Для приёма оплаты Робокассе передаются номер счёта и сумма заказа, а при заказе на странице https://pay.ai-toolbox.ru также адрес электронной почты для чека. Письма с оплаченным файлом отправляются через Яндекс Почту. Сообщения бота доставляет Telegram, его серверы находятся за пределами Российской Федерации. Другим лицам данные не передаются.

4.3. Оператор не продаёт данные и не отправляет по ним рекламу.

5.3. Уточнить, заблокировать или удалить данные можно по запросу на aitoolbox.help@yandex.ru. Данные о заказах, которые нужны для налогового учёта, удаляются после окончания срока из п. 5.1.
